# 멀티모달 모델이란?

- 하나의 모델이 텍스트, 이미지, 오디오, 비디오 등 여러 '모달리티'를 함께 입력받고 처리
- 2026년 현재 프론티어 모델에게 멀티모달은 선택이 아닌 기본값
- GPT-4o/GPT-5.5: 텍스트·이미지·오디오·비디오를 하나의 통합 모델로 end-to-end 학습
- Gemini 3.1 Pro: 설계 단계부터 텍스트·이미지·오디오·비디오·코드를 한 아키텍처로 통합, 영상 이해에 강점
- Claude Opus 4.7: 문서 중심 워크플로우와 긴 문서 OCR에 강점
- Qwen-VL(Qwen2.5-VL, Qwen3-VL): 이미지 속 텍스트 읽기, 레이아웃 이해, 객체 위치 파악에 특화
