# GitHub Copilot — Secret Protection 팀의 실전 활용기

- Secret Protection 팀이 Copilot 코딩 에이전트를 활용해 몇 주 만에 새로운 토큰 타입 약 90종을 온보딩
- 사람이 조사한 결과를 GitHub 워크플로우에 입력하면 배경 설명·API 문서 링크·예시가 담긴 이슈가 자동 생성되고, 에이전트가 PR을 자동 생성
- 반복적인 작업이 병렬화되면서 엔지니어는 더 정교한 리서치와 리뷰 단계에 집중할 수 있게 됨
- 한계: 침습성이 가장 적은 API 엔드포인트를 찾는 등 미묘한 판단은 여전히 숙련된 엔지니어가 담당
- 교훈: 기존 검증 코드·공급자 문서 같은 좋은 컨텍스트를 제공할수록 결과물 품질이 높아지며, 사람의 검토는 필수
