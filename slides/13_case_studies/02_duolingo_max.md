# Duolingo Max — GPT-4로 언어학습 재설계

- OpenAI GPT-4 기반 "Explain My Answer"(오답 설명), "Roleplay"(실전 대화 연습) 기능 출시
- 프로토타입을 하루 만에 완성 — "제로에서 95%까지는 빠르게 도달하지만, 나머지 5%는 직접 데이터를 다듬어야 한다"
- 콘텐츠 제작 속도가 40% 향상되어 6개월 만에 신규 언어 코스 7개 출시(과거엔 2년 소요)
- 커리큘럼 전문가가 AI 생성 콘텐츠의 정확성과 톤을 직접 검수
- 사용자가 오류를 신고하면 이를 모델 개선에 반영하는 피드백 루프 운영
