# 2026년 주요 모델·제공업체 지형

- Anthropic: Claude Opus 5(2026년 7월 출시, 100만 토큰 컨텍스트), Sonnet 5, Fable 5.1/Mythos 5.1, 경량 모델 Haiku 4.5(20만 토큰)로 라인업 구성
- OpenAI: 2026년 7월 GPT-5.6 계열(Sol·Terra·Luna 3단계)을 출시, 세 모델 모두 약 105만 토큰 컨텍스트를 공유하며 가격대로 차별화
- Google: Gemini 3.1 Pro가 최대 200만 토큰 컨텍스트를 지원하며 프론티어 경쟁에 합류
- 오픈웨이트 진영: DeepSeek V4, Qwen3.5, GLM-5.1, Llama 4(Scout/Maverick) 등이 코딩 벤치마크(SWE-Bench 등)에서 서구 폐쇄형 모델과의 격차를 한 자릿수 퍼센트포인트까지 좁힘
- 2025년 말 기준 오픈소스 모델의 사용량 비중이 전체 토큰의 약 3분의 1까지 성장했지만, 가장 어려운 추론 과제에서는 여전히 서구 프론티어 모델이 우위
