# 실제 비용 절감 사례

- 월 4만 7천 달러였던 LLM API 비용을 시맨틱 캐싱 도입 후 월 1만 2,700달러로, 약 73% 절감한 사례가 보고됨
- 구조화된 JSON 출력으로 전환해 응답 토큰을 약 200개에서 30개로 줄여 월 2,400달러를 절감한 사례도 있음
- 시맨틱 캐싱과 예산 인식 라우팅을 결합해 지출을 47% 줄인 프로덕션 배포 사례도 보고됨
- 소형 모델(간단 작업)과 대형 모델(복잡 추론)을 혼합하는 하이브리드 추론 전략으로 비용을 60% 절감한 대기업 사례도 있음
- 캐싱·라우팅·배치·압축을 함께 적용하면 70~85% 수준의 비용 절감이 현실적으로 보고되는 범위
