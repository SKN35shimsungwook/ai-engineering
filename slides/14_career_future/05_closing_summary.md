# AI 엔지니어링, 무엇을 남기는가

- LLM 기초부터 RAG, 에이전트, MLOps/LLMOps, 파인튜닝, 평가, 보안, 멀티모달까지 — 계속 넓어지는 응용 분야
- 공통적으로 요구되는 자세: 빠른 프로토타이핑 능력과 프로덕션 수준의 신뢰성·평가·보안을 함께 갖추는 것
- 실제 사례(Duolingo, Shopify, Slack, GitHub 등)가 보여주듯, 기술 자체보다 '무엇을, 얼마나 안전하게, 얼마나 빠르게' 프로덕션에 올리느냐가 관건
- 수요는 빠르게 늘고 있지만 진입장벽도 함께 높아지는 중 — 꾸준한 학습과 실전 프로젝트 경험이 핵심 경쟁력
- 이 발표자료가 다룬 여러 챕터는 AI 엔지니어링이라는 분야의 입문 지도일 뿐 — 실제 실력은 직접 만들어보며 쌓인다
