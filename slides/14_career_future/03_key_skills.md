# 꼭 갖춰야 할 핵심 스킬

- 프로그래밍: Python이 채용 공고의 약 71%에서 요구되는 핵심 언어, SQL·Java도 함께 요구됨
- LLM 실무 스킬: LLM API 활용(OpenAI, Anthropic 등), RAG 아키텍처, 멀티에이전트 오케스트레이션, 평가(evals)와 관측성(observability), 비용 최적화
- 인프라/클라우드: Docker(15.4%)·Kubernetes(17.6%), AWS(26%)·Azure(33%) 등 클라우드 플랫폼, PyTorch(37.7%)·TensorFlow(32.9%)
- 학습 순서 추천: Python과 LLM API 호출부터 시작해 프롬프트 엔지니어링과 평가로 확장 — 보통 8~12개월 정도의 자기주도 학습이 현실적
- 학습 자료 예: roadmap.sh의 AI Engineer 로드맵, YouTube의 실전 로드맵 영상
