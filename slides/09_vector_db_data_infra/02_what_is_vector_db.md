# 벡터 데이터베이스란 무엇인가

- 텍스트, 이미지 등을 임베딩(embedding)이라는 고차원 숫자 벡터로 변환해 저장하는 DB
- 키워드 일치가 아니라 "의미상 가까운" 벡터를 찾는 근사 최근접 이웃(ANN) 검색이 핵심
- RAG 파이프라인에서 사용자 질의와 관련된 문서 조각(chunk)을 빠르게 찾아주는 역할
- 수백만~수십억 개 벡터에서도 밀리초 단위 응답을 내기 위해 특수 인덱스 구조를 사용
- 메타데이터 필터링(예: 날짜, 사용자 권한)을 벡터 검색과 함께 지원하는 것이 실무의 관건
