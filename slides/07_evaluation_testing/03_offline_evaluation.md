# 오프라인 평가: 골든 데이터셋과 벤치마크

- 골든 데이터셋(golden dataset)은 정답/기준이 명확한 예시 모음으로, 배포 전 회귀 테스트에 사용
- 코드 기반 채점(정확하지만 경직됨), 모델 기반 채점(유연하지만 비결정적), 사람 채점(품질은 최고지만 비용이 큼) 세 가지 채점 방식을 조합
- 실전 팁: 처음부터 수백 개를 모으려 하지 말고 실제 실패 사례에서 뽑은 20~50개 태스크로 시작
- 채점 기준은 두 명의 전문가가 독립적으로 봐도 같은 판정이 나올 만큼 명확하게 작성해야 함
- 100% 통과율을 달성한 평가는 회귀 테스트 스위트로 옮기고, 계속 어려운 새 케이스로 벤치마크를 갱신

> Source: [Demystifying evals for AI agents](https://www.anthropic.com/engineering/demystifying-evals-for-ai-agents)
