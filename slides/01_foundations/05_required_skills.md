# 필요한 역량

- 소프트웨어 엔지니어링 기본기: API 통합, 시스템 설계, 테스트, 배포 파이프라인 구축 능력이 딥러닝 이론보다 우선
- 프롬프트 설계 및 반복 실험 능력: 모델의 입출력을 다루는 감각과 체계적인 실험 프로세스
- 시스템적 사고: 지연 시간, 비용, 정확도, 안전성 사이의 트레이드오프를 함께 고려하는 능력
- ML 엔지니어보다 통계·모델 내부 구조에 대한 깊은 이론 지식은 상대적으로 덜 요구되지만, 평가(evaluation) 설계 역량은 오히려 더 중요해짐
- ML 역할은 통계적 모델링과 데이터 전처리에 집중하는 반면, AI 엔지니어는 더 폭넓은 소프트웨어 개발 및 시스템 아키텍처 지식을 요구받음
