# 에이전트 메모리: 단기 vs 장기

- 단기 메모리(Short-term): 현재 컨텍스트 윈도우 안에 있는 정보 — 최근 대화, 진행 중인 작업 상태
- 장기 메모리(Long-term): 세션을 넘어 지속되는 사실·선호도·과거 결과를 저장, 몇 주/몇 달 뒤에도 참조 가능
- LLM 자체는 API 호출 사이에 아무것도 기억하지 못하는 무상태(stateless) 시스템 — 메모리는 별도 인프라로 구현
- 전형적 구조: 저장용 DB + 임베딩 모델(의미 검색) + 추론 시점에 관련 정보를 프롬프트에 주입하는 검색 메커니즘
- 컨텍스트 윈도우가 커지는 것만으로는 부족하며, 정보 추출·통합·색인·랭킹된 검색이 장기 메모리의 실질적 가치를 만듦
- 관계가 복잡하거나 시간 민감도가 높은 경우 벡터 검색보다 그래프 기반·하이브리드 메모리가 더 적합할 수 있음
